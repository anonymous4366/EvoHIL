# EvoHIL

Project page for **EvoHIL: Self-Evolving Reward and Flow-Matched Policy Optimization for Robust Human-in-the-Loop Reinforcement Learning**.

The page presents the method, cross-embodiment evaluation, illumination-shift results, motion comparisons, and 16 real-robot demonstrations. The manuscript is not distributed in this public repository.
